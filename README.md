# NftPivot

NftPivot: A High-Performance Real-Time Data Processing Engine for Scalable, Cloud-Native Logging and Analysis at Core.

NftPivot is built to be simple and practical, focusing on doing one thing well.

## Installation

1. Clone the repository: `git clone https://github.com/vishalrankhamb/NftPivot.git`
2. `cd NftPivot`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
